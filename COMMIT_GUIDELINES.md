# Commit Guidelines

Use Conventional Commits:

```
<type>(<scope>): <subject>
```

- Keep commits small and focused on one feature or fix.
- Use the imperative mood in the subject (e.g., "add", "fix", "remove").
- Scope is optional but encouraged for modules/domains (e.g., `deployment`, `ci`, `docs`).
- Types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `ci`.
- Avoid large mixed commits; split by logical change.
